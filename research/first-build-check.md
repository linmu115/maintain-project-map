# 首版独立试用与交付检查

日期：2026-09-15。此文件属于本 Skill 的开发资料，不随个人 Skill 安装，也不在普通项目维护中加载。

## 试用设置

采用一次独立前向使用，子智能体不继承当前分析上下文，不获得预期答案、验收标准或其他代理报告。只提供最终 Skill、隔离的合成归档工作流及自然任务：修好不同目录同名材料只剩一份的问题，并查回以前的“分享卡片”为何取消。

原始夹具保留在 `tests/fixtures/forward-project`，运行副本位于 `.work/forward-1`。没有注册测试地图，也没有调用外部模型 API。本试用不构成无 Skill 基线实验。

## 可观察结果

| 关注点 | 本轮实际结果 |
|---|---|
| 修复行为 | 副本独占创建；名称占用时加递增序号；来源清单对应实际输出名 |
| 早期约束 | 来源映射、输入原件和已有输出保留；没有缩减原始要求 |
| 提议与范围 | 语义检索仍为提议，本轮未实现 |

| 来源诚实性 | 明确历史为合成事件，未声称是真实用户原话；本轮请求另存 |
| 接口可读性 | 用文件命名例子解释输入输出及对消费者的影响；外部消费者未提供，保留未核查限制 |
| 记录维护 | 需求、接口、实现、验证、入口及代码共 6 个已有文件改变；新增本轮来源和焦点检查脚本 |

根代理重新执行三个真实 CLI 场景：不同目录同名材料、已有同名与自然带序号文件、输出目录与输入来源重叠；均通过。每个场景检查输出与原件字节、映射和已有材料。适用代码 SHA-256 为 `3568973fce48024541033eab4828a7576aaae43b6fdab10abf9a293e3640c765`。

试用有一项范围问题：一次直接 Git 状态查询向上落到了用户主目录仓库，列出范围外路径；子智能体停止了后续 Git 查询，没有读取这些文件或编造提交依据。地图脚本自身的 Git 状态查询已限定到声明文件；本轮并未证明所有代理自由使用工具的操作都能保持同样范围。
