# 直接迁移 Archify 逻辑并嵌入阅读页面

2026-09-15，用户在“地图的数据组织、项目 ID、位置登记、检索、合并与退役”的来源说明上批注“直接迁移 Archify 逻辑”，在“A/B/C 阅读界面、侧栏、搜索、独立滚动、本地 HTTP 服务”上批注“做适配性嵌入”。

## 实施范围

- 原生 Archify JSON 作为图的一手资产，保留节点和关系 ID、分组、边界、布局、泳道与引导视图；使用上游的校验、交付和节点搜索、上下游及路径工具。
- A/B 页面适配嵌入原生图，保留低饱和浅色、固定导航和独立滚动。项目记录与图节点通过独立映射关联，允许多对多，不重写图模型或拓扑计算。
- 上游没有的项目 ID 登记、跨地图解析、需求档案、实现与验证分存、记录合并退役作为补充层保留；不宣称这些能力来自 Archify。
- 不导入上游全量 Skill 指令作为必读上下文。仅在图的编写或阅读任务中按需查阅相关原生规范。

## 验收描述

原生 JSON 的身份、字段和内容在导出中保留；更改图源会改变地图指纹。上游生成原版与浅色嵌入版本分开保存，回执明确各自字节哈希。图源无效时仍能阅读文档，并显示该图不可用，不悄悄引用旧图。没有声明图源时不从记录排列猜测结构。
