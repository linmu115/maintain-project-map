# 语义护照跳转、按需更新记录与页面返回

取消图下“图节点与项目记录”抽屉。点击图卡片后的原生语义护照展示该节点对应的项目条目，沿用原来的节点名称与条目按钮样式；一个节点关联多条记录时全部保留。

侧栏在“项目概览”“项目条目”之后加入“更新记录”。它记录开发者希望留存的一次迭代带来的功能变化，仅在用户明确要求“把本次迭代加入更新记录”等情形追加。普通维护、完成任务、提交代码或导出页面不会自动追加，也不从 Git 或验证日志自动拼出更新。

条目包含日期、标题、功能变化及必要背景。发生图结构变化时可以链接现有 architecture/workflow 图和稳定节点 ID；点击链接进入对应图并把该节点放到画布视觉中心。未变化时不要求图链接，节点失效时明确提示。

顶栏提供返回按钮，恢复此前的页面、条目、页签、搜索与文档滚动位置；从护照进入条目后返回时还应恢复图中所选节点与相机位置。初始入口没有可返回的地图状态时禁用。
