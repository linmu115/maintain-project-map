# 点选文档内的图形后才启用画布操作

2026-09-15，用户指出选中流程图后应转为 canvas 式交互：鼠标缩放、点击拖动画布；现有缩小范围不足，部分图形落在界面外。

用户随后澄清：图在长文档中，先点击选中图形窗口，才进入画布交互；点击窗口外部后恢复原来的文档滚动。本要求更正了此前把正文主面板改成整块画布的错误理解，不是功能退役或失败探索。

- 保留原来的 A/B 文档布局、固定导航以及侧栏和正文独立滚动。图形嵌在原来的文档位置。
- 默认不选中图形，鼠标即使位于图上，滚轮仍滚动正文。
- 点击图形窗口才选中它。首次点击仅选中窗口，不同时触发图内节点操作。选中后，滚轮以鼠标位置为中心缩放，空白处按住左键拖动画布；原生节点点击与查找工具继续可用。
- 点击图形窗口外部即取消选中并恢复正文滚动。多张图同时存在时至多选中一张，切换文档后不遗留选中状态。选中与退出不重载图，保留相机位置。
- 首次按窗口宽高完整适配图，允许缩小到适配比例的 5%，可一键恢复全图。选中状态有轻量提示和返回文档按钮。
- 完整图范围包括外绕连线、箭头和标签；不能在图形进入画布前把越过旧边界的内容裁掉。2026-09-15 用户截图指出右侧连线截断，放大缩小无法恢复，应修正完整图范围与裁切层级。
- 用户进一步明确：黑框仅为固定在展示窗上的选中提示和视野边界。窗口、边框及工具栏不随缩放或拖动变化，只有内部画布内容缩放和平移；不能移动整个 SVG 元素来模拟此行为。

该行为适用于人读页面的图形嵌入；图源几何与上游原版文件保持独立，调整记录为下游交互适配。
