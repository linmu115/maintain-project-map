# 固定导航与独立滚动阅读区

2026-09-15，用户要求固定侧边栏和顶边栏，侧栏和正文各有独立滚动条。

阅读窗口固定在视口内，顶栏和阅读方式切换区保持可见；侧栏内容与正文各自占据剩余高度并独立滚动。选择侧栏条目时保留侧栏滚动位置，避免目录跳回顶部。小屏仍保留两个独立的滚动区域；打印时恢复完整文档流。
