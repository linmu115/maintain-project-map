# 默认通过本地 HTTP 地址阅读地图

用户在区分 HTML 文件入口与 HTTP 入口后，选中了 `http://localhost:…` 的方案。此前直接交付 HTML 文件路径的默认方式由此调整。

## 验收

- 生成地图的常规命令返回可供开发者打开的本机 HTTP 链接。
- 重复生成同一位置的地图可复用预览服务与地址；刷新后读取新的导出内容。
- 服务只监听本机，只提供本次阅读导出的页面与图形；有明确的状态和停止操作。
- 保留无需启动服务的纯 HTML 导出，地图的身份、源记录及 A/B 阅读方式不变。
- 不增加聊天入口或后台 LLM 调用；页面仍是按需更新的快照。
