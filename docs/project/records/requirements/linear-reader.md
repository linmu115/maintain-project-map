# Linear 式黑白阅读工作区

2026-09-15，用户选定 Linear 方向：“配色白色为主，黑色为辅，不需要杂色，界面逻辑就参考 linear”。

- 白色内容区、黑色主文字、中性灰辅助文字与分隔；页面和嵌入图去掉黄蓝及灰绿色强调。
- 固定左侧导航统一容纳两种阅读方式、搜索和当前目录；内容区使用紧凑页签，减少大卡片、重复边框和说明性装饰。
- 原记录、项目 ID、版本与来源仍可查，技术元数据收进详情，避免抢占主要阅读空间。
- 保留 A 项目概览、B 围绕一项的能力；页面切换可通过地址恢复，浏览器前进后退恢复对应阅读位置的选择。
- 顶栏固定，目录与正文独立滚动；小屏通过目录开关展开导航。
- 保留文档内图形的点击激活、点击外部退出、原生图查询和修复后的引导布局。
- 页面仅用于阅读，提问继续使用会话 harness。

来源：当前任务用户明确选定 Linear 的消息。参考官方设计说明 https://linear.app/now/behind-the-latest-design-refresh 中减少导航噪声、紧凑页签与突出正文的原则；不复制与项目地图无关的任务管理操作。

2026-09-16 当前修订：用户要求停止维护“连续文档”。当前设计只保留项目概览与项目条目；模板、导出参数和安装版同步移除旧模式。已有带条目身份的旧地址转到该条目，Git 历史仍可回查原实现。这是功能退役，不是失败探索。
