# 可迁移的模块目录、正文链接与关系表达

文件夹中的模块和子模块应直接出现在 B 的可展开目录里，搜索保留祖先位置。开发者能从提供方正文跳到消费方接入说明、返回唯一合同，并进入相关章节或原始资料。

优先复用现成的 Markdown/Wiki 处理能力，保持现有 A/B 与原生 Archify 阅读方式。普通链接和 Wiki 语法可以共存，稳定记录 ID 可在文件移动后继续定位；同名标题不能随意选一个目标。

反向展示不需要双方各声明一条相同关系，不同角色与版本的关系仍须保留。正文阅读链接不等于真实调用依赖。Skill 按需指引 AI 自行分析具体消费能力和依据，不能只修正 DSH 的一段措辞；新指引适用于软件、工作流及 Skill。

默认图形字号与缩放不属于本次返工项。检查本次地图表达与阅读行为，不以地图构建成本、耗时或产物长度判断 Skill 是否提高后续开发效果。
