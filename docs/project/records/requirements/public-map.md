仓库首页提供稳定的在线地图入口。发布使用 GitHub Pages，文档、架构与流程图、记录跳转和显式归档阅读可在浏览器中使用，无需读者安装 Python 或启动本机服务。

主分支推送后自动从仓库中的权威资料构建页面。地图 Markdown、清单、图源、归档和实现随 Skill 一起版本管理；生成页面作为发布产物，不作为第二套权威文档提交。

在线版本保留开发历程叙述，但不发布本机 Codex 原始会话、事件索引、绝对路径或服务回执；证据入口清楚说明在线不可用。公共导出限定到明确指定的资料根目录，使用空输出目录，避免把旧本机导出残留混入发布。

验收：本机安装副本与仓库分发文件一致；查询/源码发现/归档回归通过；公共构建不依赖本机证据文件；GitHub 发布成功后，验证在线地图与图、文档和归档的实际链接。
