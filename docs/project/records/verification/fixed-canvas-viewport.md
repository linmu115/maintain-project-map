# 固定视窗与内部画布移动检查

2026-09-15，适配版本 project-map-fixed-viewport-v6。

## 原因与改动

架构图原 SVG viewBox 是 0 0 1048 726，外绕连线经过 x=1060，标签也超出旧范围。下游阅读副本在相机初始化前读取完整内容边界，加上留白，得到 -12 -12 1117.800048828125 750。没有修改图源节点或连线路由。

用户进一步指出视窗应固定。当前 SVG 元素保持固定位置，内部 data-map-content 分组执行相机变换；选中框是外层独立覆盖边框。原相机额外 clip-path 在 canvas 模式停用，SVG 固定视窗负责裁切。导出完整图时移除内部相机变换。

## 验证

- 9 项相机、6 项激活与 14 项阅读导出检查合计 29 项通过。新增边界案例覆盖外绕连线/负坐标、重复调整窗口不累计扩大边界、原版非 canvas 模式不变。指针定位测试检查留白、缩放和平移下的内部矩阵。
- 嵌入页面从 100% 放大至 175% 后，SVG 的 left=14、top=101.3333、width=581.3334、height=441.6667 全部不变；内部矩阵从单位矩阵变为 matrix(1.75 0 0 1.75 -410.1750 -272.25)。根 SVG 的 CSS transform 为 none。
- 完整图页实际拖动 300 像素：SVG 的位置与 1252 × 553.6667 尺寸不变，内容矩阵横移从 -273.4500 变为 -679.5872（对应屏幕 300 像素）。重置后回到 100%。
- 在窄于图源宽高比的嵌入窗口，“交付阅读链接”的连线和标签均完整处于视野中。
- 本次嵌入 iframe 内的自动拖动受浏览器工具的坐标检查限制，实际拖动检查使用相同适配脚本的完整图页；嵌入层的点击激活由既有自动检查和页面操作覆盖。

原生 Archify 上游文件保持不变。本次不是长期使用或模型效果评估。
