# 开发历程支持可追溯阅读与按需取证

原 HTML 的侧栏在“更新记录”下方增加“开发历程”，沿用现有 UI 和返回导航。列表展示任务标题、时间、涉及模块、结果和摘要；正文沿问题、主要尝试、实际反馈、关键转折和保留边界组织，帮助开发者理解项目怎样推进。

1. **叙述可以查回依据。** 相关段落提供可展开的来源入口，工具调用与返回按同一调用身份配对，长内容分段读取。整理正文注明来源范围及适用版本，未记录的选择理由保持缺失，不事后补造。
2. **复用 Codex 原会话。** 地图保存事件定位和内容指纹，原始消息及工具输出继续由宿主保存。本轮已移除试做时的整段原文副本和重复导出片段；展开依据时才读取所选原文，来源被删除或改变时给出明确提示。
3. **模型自主决定读取深度。** 可先查少量任务摘要，再搜索选中任务的事件、读取配对与有限上下文，最后按返回的偏移继续。普通地图查询不打开原始事件，也不自动把旧任务日志注入上下文。历史失败保留条件，供后续判断。
4. **真实任务验证了阅读链路。** 首例为 MRS 的“研究地图改为策略泳道”，展示分支拆分、布局检查失败与修正、原稿往返和交付边界。默认采用文字叙述和折叠证据。

使用方式见 [[MOD-development-history|开发历程与按需证据]]、[[IF-history-query|模型查询接口]]；当前实现见 [[IMP-development-history]]。架构入口：[阅读页面](map-node:architecture/reading-shell)。
