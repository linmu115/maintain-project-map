# 开发者阅读页面

用于生成或解释项目地图的人读视图。普通编码和记录维护无需加载本文或渲染页面。

## 生成

scripts/render_map.py 从当前 project.yaml 与原记录生成阅读入口，默认启动或复用本机 HTTP 服务，并返回阅读 `url`；对用户优先提供这个地址。纯 HTML 导出使用 `--export-only`，具体参数和停止方式见[本地操作](operations.md)。页面携带本次读取的内容指纹与版本，是该次导出的快照；原记录有变化时重新生成并刷新。HTTP 服务不自动更新记录，打开旧页面不能据此认定内容仍是当前状态。

A/B/C 使用同一份记录与身份：

- A 分面板：项目说明与规格、整体组织、功能路径分别展开；说明下区分做到哪和缺什么。
- B 围绕一项：在当前地图中选择能力、对象、模块或决定，结合相关说明、关系与现状。
- C 连续阅读：沿项目说明的章节理解目标、对象、设计与交互，图和来源放在相关处。

选择默认模式是阅读偏好，不改变地图身份。地图缺少某类材料时显示实际缺口，不生成假的实现进度或猜测流程。

## 原生 Archify 嵌入

架构和工作流读取 project.yaml 中明确登记的 Archify JSON，直接使用上游校验、交付和阅读逻辑。图源保留原节点与关系 ID、布局、分组、边界和流程语义；页面不再根据项目记录列表重建图。节点通过独立映射关联项目记录，一项可以对应多个节点，一个节点也可以对应多项说明。

A 的主图和 B 的相关图保留原生图内工具；外层负责项目文档导航与记录搜索。B 有多个关联节点时允许逐个选择，没有关联时给出说明和整体图入口，不虚构聚焦。C 按需展开紧凑图，并保留完整图入口。顶栏固定，侧栏与正文各自滚动。默认图页采用黑白与中性灰，图源详情另提供未改样式的 Archify 原版页面。

图形保持嵌在文档中，默认滚轮滚动正文；点击图形窗口才选中并启用滚轮缩放、空白处左键拖动。点击外部或“返回文档”取消选中，多图至多选中一张。选中状态切换不重载图，不重排正文。图内按窗口宽高适配全图，允许缩到适配比例的 5%；“适应全图”或图内的 0 恢复。

未登记某种图不代表项目失败或功能缺失；有明确需求时再编写图源。已登记图源失效时显示诊断，其他记录继续可读，旧图不能作为本次成功结果。views 中的 JSON 和 HTML 是导出快照，不能据其存在自动认定它们是当前权威资料。

只有新增、修改或比较图源时才查看[Archify 图源维护](archify-authoring.md)。需要解释某项原生图内能力时，按需查阅[上游阅读器说明](../assets/vendor/archify/references/viewer-runtime.md)，无需复制实现图内搜索和拓扑查询。

## 阅读职责

人读页面参考 Linear 的紧凑工作区：白色为主、黑色文字，中性灰分隔，不使用杂色。左侧固定阅读方式、搜索和可滚动目录；正文使用紧凑页签与列表。项目身份和快照信息收进顶栏详情，地址记录模式、条目、面板与页签。小屏用目录开关访问导航。图内原生阅读引导以可展开区域呈现，内部按实际内容高度排布，超出时滚动整个引导内容区；不要用小比例高度压缩网格行再隐藏溢出。样式属于按需生成的人读资产，不放进 Skill 入口。

页面服务开发者理解、浏览和查找。提问继续使用现有会话 harness，不增设聊天框、发送桥接或专用提问入口。LLM 根据用户提供的名称、位置或引用查询原记录，不假定知道用户正在看哪页。

先解释项目能做什么、对象是什么、为什么这样协作，再给具体字段和代码入口。人读说明来自有来源的记录，不能只展示机器字段。不同阅读方式不各自维护一份需求。

实现记录优先解释当前行为、用法与已知限制。验证记录独立访问；已知失败或未验证状态会影响使用时，应在实现说明中简短提示。不能把提议写成已确定缺口，或把文档已经写好称为功能已经实现。

外部地图只显示项目 ID、必要记录 ID 与简短关系，通过已登记位置按需打开。目标不存在时保留引用；不自动加载相邻项目全图。

页面切换、搜索、展开和已生成图的浏览由本地代码完成，不调用模型。图源明确使用远程品牌素材时，原生 Archify 的素材获取可能联网。原生交付回执与浅色适配副本分别记录文件指纹；图通过校验不等于项目功能已经实现或验证，也不代替实际视觉检查。

画布层级：外部选中边框、工具栏和 SVG 视窗固定；仅内部图形分组应用缩放和平移。完整图边界应包含外绕连线、标签及留白，不能只按节点外框裁切。完整图导出要清除交互相机变换。
