# 检索与来源

已有精确位置时直接读取原文。这里用于模糊查回、来源核对、长会话和跨项目定位，不要求普通修改逐条执行。

## 从当前问题缩小范围

- 已知记录 ID：读取该记录，区分当前状态与历史去向。
- 需要补查源码入口、导入和未登记依赖：使用 `project_map.py source` 的有界入口，见 [源码发现与说明归档](source-and-archive.md)。既有检索结果不会被当成完整代码图。
- 当前规格：先查有关要求、接口和实现；需要理由时再追来源。
- 当时的选择：读对应决定和原消息，核对后来是否被替代。
- 只记得叫法或近似意思：搜索短问题、中文词或多个关键词；按问题选 `--kind`，用命中片段判断候选。默认 auto 使用已配置的本地混合检索；结果明示 lexical/semantic，双字词面回退仍标记 partial_terms。需要严格匹配时用 `--match all/phrase`。
- 旧名或退役功能：用 `--include-history` 包含历史状态，先解释退役/合并原因与后继。current 状态的历程也不是当前接口或实现；可按类型筛选。
- 外部引用：用项目 ID 和可选记录 ID 解析目标，只打开必要内容。找不到目标保留原引用；多个工作树不猜一个位置。

地图脚本的 search/read/related/resolve 返回候选或正文与精确位置，命令见[本地操作](operations.md)。先用默认简短输出，需要核对完整元数据再用 `--detail full`。命中不等于核实；读取被截断时使用返回的后续位置继续。关系只描述已登记范围，不能证明没有其他消费者。来源的 no_baseline 不代表新鲜，needs_review 只说明文件与已核对基线不同，仍需判断说明是否受影响。

## 本地混合检索

只索引选定地图已声明的记录正文与摘要，按标题、段落分块，附项目、模块和记录名称供模型理解。保留每段的原文位置；嵌入时去掉 Markdown 链接的冗长目标路径，返回片段仍用未改写的原文。源码目录、来源文件正文、原始会话和其他项目不会因语义查询自动展开。

词法和语义分别排序，语义先把同一记录的多个片段合为最佳一项，再以 `1 / (60 + rank)` 做等权 RRF，精确 ID/名称优先。每路取前 50 个记录，在固定候选并集内分页；长文不会因片段多得到多票。RRF 分数和余弦相似度只用于排名，不能解释为事实置信度或召回率；没有校准的“必然相关”阈值，陌生问题也可能返回候选。两路共享状态、类型和模块过滤，不借语义回退越过范围。[RRF 约定](https://www.elastic.co/docs/reference/elasticsearch/rest-apis/reciprocal-rank-fusion)

当前适配是固定版本的本地 BGE small 中文 ONNX，512 维，CPU 推理；安装命令见[本地操作](operations.md)。采用模型说明中的 CLS、归一化及查询前缀；配置与模型校验值一起标识向量空间，不混用模型版本。[模型说明](https://huggingface.co/BAAI/bge-small-zh-v1.5)

向量缓存放在本机，按地图位置、项目 ID 与模型空间隔离。每次查当前文件，用内容指纹复用未变片段，只补算变化部分；结果正文从实时记录取，不从缓存恢复。删除记录不再参与检索，归档只在显式包含历史时参与。缓存不修改权威文档，缺失可重建；损坏向量会重算，整个缓存或模型不可用时 auto 披露降级，显式 hybrid 则报错。完整诊断可用 `--detail full`，日常无需读取。

## 长会话

优先使用宿主现成的任务读取工具及分页。需要补查且原记录可读时，只定位用户指定任务对应的文件，不扫描所有会话。

本 Skill 提供 scripts/search_session.py，读取明确指定的 Codex JSONL 文件中的可见消息，默认只查用户消息。它不读取模型内部推理、工具输出或未知类型作为消息，也不自动复制会话进入地图。

搜索回执包含消息 ID、任务 ID（源文件提供时）、文件位置、文本摘要校验值和覆盖范围。没有原生 ID 时使用文件位置与摘要，并明确身份较弱。特别长的消息按 Unicode 码点分段；不同工具不能假设偏移单位相同。

这只是一个 Codex 原记录适配器；其他宿主继续使用各自接口。格式未覆盖、正文不可访问、搜索无命中分别说明，不能都当作历史中不存在。

## 引用与有效性

来源可保存 provider/thread_id/message_id，或文件/章节/版本，加少量必要摘录；代码可以保存路径、符号与 Git 提交。历史命令是证据，不获得当前执行权限。

发生冲突时回看后续修订与当前用户要求。实现观察不能反向改写需求。源文件移动或变化后核对位置；不能把相似的新对象冒充原条目。

复用仍适用的已读内容。索引和页面可重建，原始文件与宿主消息仍是来源；不要用全量历史注入代替检索。Skill 不控制宿主压缩或承诺模型永久记住全部上下文。
