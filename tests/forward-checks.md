# 小范围前向使用检查

本文件属于开发测试，不随日常 Skill 入口自动加载。夹具为 `fixtures/forward-project`；项目身份与内容独立，不登记到个人默认注册表。所有历史事件为合成数据，不能当成真实用户原话。

## 首轮使用方式

等运行器、阅读器与最终 Skill 就绪后，再复制夹具到独立临时目录进行前向使用。先给使用者一个自然任务，例如修复来自不同目录的同名材料覆盖问题，保留原件和出处，并询问“之前那个分享卡片为何没了”。使用者只得到任务、最终 Skill 和原始夹具，不得到下面的预期结果。对照结果保存在独立测试回执中，不回填成夹具原有历史。

夹具准备完成后，2026-09-15 已执行一次隔离子智能体前向任务，根代理检查产物并重跑三项 CLI 场景；结果见 [首版试用](../research/first-build-check.md)。未执行无 Skill 成本对照，也未调用外部模型 API。

## 七项核心验收

1. **早期要求继续有效。** 修复同名归档问题时保留来源映射与原件保护，不为让代码通过而缩减归档要求；源码和必要的输出行为确实改变。
2. **提议保持提议。** 不把尚未明确的语义检索加入本轮实现或确定缺口，也不叫它失败路线。
3. **退役和失败分开。** “分享卡片”可用旧称检索到，解释为后来取消自动共享；同步探索只在需要传播删除的条件下失败，不能泛化为所有复制归档均失败。
4. **接口与人的理解同步。** 命名或交付约定变更后，入口先说明用户交什么、从哪找结果、失败怎样处理；技术字段与代码保持对应。消费者不能访问时明确未核查。
5. **实现与验证独立。** 实现页写实际使用方式与限制；运行命令、检查范围、结果写独立验证文件。未执行、部分输出、历史合成失败都不能伪装成本次通过。
6. **薄引用与精确来源。** 外部 ID 保留、按需解析；目标未登记时报告无法定位，不猜同名项目、不扫描个人所有地图。来源可回到真实存在的 EVT 段落；不得把合成文字引用成用户原话。
7. **维护有界且可恢复。** 只改与任务有关的记录；纯拼写修复允许零地图变化。索引或生成视图不可用时可继续读源文件。三种页面呈现同一事实，不要求为测试重写全部记录或强制加载三种视图。

## 已知陷阱

- `status: failed` 同时出现在探索和验证记录；应结合 `kind` 理解，不能把所有历史记录标为失败。
- `MOD-auto-share` 的旧别名不在当前能力列表中；默认筛选可以隐藏它，明确旧名/ID 检索应能找到。
- `MOD-archive` 的外部引用故意不可解析；这个状态是覆盖范围提示，不是整张地图损坏。
- `VER-archive-v1` 没有运行记录，`VER-overwrite-sync` 是合成历史案例；不得据此宣布当前入口已验收。
- 当前代码特意保留同名覆盖缺口；测试作者不提前修复，前向任务才能检验记录是否真正影响开发行为。
- 文件中的来源位置必须实际回读核验；仅匹配标题或摘要不构成已确认需求演进。

这些检查关注功能正确性与维护行为，不能据一次成功宣称 Skill 已优于无 Skill 基线。后续成本对照应把首次接入、检索、维护和返工一并计入。
